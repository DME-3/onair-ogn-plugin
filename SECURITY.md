# Security and privacy reports

This plugin is experimental and processes untrusted radio input. The latest
published version is the supported version for fixes.

For a vulnerability, use the repository's **Security → Report a vulnerability**
control when available. If that control is unavailable, contact a maintainer
through their public GitHub profile for a private reporting route. Avoid
posting exploit details, credentials or private captures in public issues.

Provide the plugin and OnAir versions, platform, expected impact and a minimal
synthetic reproduction. Do not send real-world recordings, decoded positions
or identifiers unless a private sharing arrangement has been agreed.

The manifest requests no permissions. Network access and automatic recording
or decoded-data export are not part of the plugin. Optional OnAir automation
events are local and disabled by default. Error-correction parity does not
authenticate a radio sender.
