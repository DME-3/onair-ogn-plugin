# Changelog

## 0.1.0 — initial public source

- macOS OnAir ABI 1 plugin for combined and individual OGN1 M1/M2 reception.
- LDPC validation/correction, TEA dewhitening and standard position, status,
  information and wind decoding.
- Missing-value handling, centre override and optional local result events.
- Public-vector and synthetic-IQ tests, SDK replay host and universal package
  builder with complete corresponding source.
- Documentation, contribution templates and macOS CI.

Experimental: Intel runtime and full OnAir GUI installation are not yet
verified. Higher-error LDPC recovery uses hard decisions and can miscorrect.
No binary release is implied by this initial source publication.
